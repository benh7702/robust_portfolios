# Generated results

These files were produced by:

```bash
PYTHONPATH=src python scripts/run_research.py --bootstrap-reps 2000
```

Outputs:

- `performance_summary.csv`: full-sample performance and risk metrics.
- `bootstrap_vs_equal_weight.csv`: moving-block bootstrap comparisons with 1/N.
- `monthly_net_returns.csv`, `monthly_gross_returns.csv`, `monthly_turnover.csv`, `monthly_costs.csv`: monthly audit trail.
- `weights_*.csv`: out-of-sample target portfolios.
- `selected_hyperparameters.csv`: parameter selected before each test month.
- `regime_summary.csv` and `stress_period_summary.csv`: conditional analyses.
- `optimizer_failures.csv`: solver failures; the completed run contains none.
- `run_metadata.json`: input dates, strategy configuration and run dimensions.
- `figures/`: report-ready charts generated by the pipeline.
